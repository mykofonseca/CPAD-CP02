# Lista de Compras do Maykon — CheckPoint 2 (React Native + Expo)

App simples de lista de compras usando `FlatList` + `useState`.

- Título do app
- `TextInput` para digitar o item
- Botão "Adicionar" (atualiza o estado com spread, sem `.push()`)
- `FlatList` exibindo os itens
- Toque no item para marcar/desmarcar como comprado; `✕` remove o item
- "Limpar tudo" esvazia a lista (com confirmação)

## Rodar
```
npm install
npx expo start
```

> `node_modules/` está no `.gitignore`.
